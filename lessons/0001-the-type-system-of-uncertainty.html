The Type System of Uncertainty

Lesson 0001 · ~12 minutes · Foundations for everything that follows

Every good decision under uncertainty starts the same way: write down what could happen. Not what you think will happen — the full list of possibilities. Probability theory is, at its core, a type system for uncertainty: it forces you to declare the space of outcomes before you're allowed to reason about any of them.

Today you'll earn three symbols and one trophy formula. That's the whole lesson.

1 · The sample space: declaring your types

Imagine rolling a single six-sided die. Before probability can say anything, it needs the set of every possible outcome. That set is called the sample space, and it gets the most majestic symbol in the subject:

Ω  ("omega" — the sample space)
Plain language: the set of every outcome that could possibly occur. Nothing outside Ω can happen.
type Die = 1 | 2 | 3 | 4 | 5 | 6; // Ω is the union type of all outcomes

Just like TypeScript won't let a Die hold the value 7, probability won't let you reason about outcomes outside Ω. A single result of the experiment — one roll — is written with the lowercase letter:

ω ∈ Ω  ("omega is an element of big-Omega")
Plain language: ω is one specific outcome. The symbol ∈ means "is a member of" — the mathematical set.has().
const ω: Die = 4; // one concrete value of the type — ∈ is the type annotation ":"
Reading tip: capital Ω = the whole type, lowercase ω = one value of it. Math reuses this capital/lowercase convention constantly, exactly like Type vs value.

2 · Events: predicates over the sample space

Here's the move that unlocks everything. You rarely care about one exact outcome — you care about questions like "did I roll an even number?" A question like that carves out a subset of Ω, and that subset is called an event.

A ⊆ Ω  ("A is a subset of Omega" — an event)
Plain language: an event A is any collection of outcomes. "Rolled even" is the event A = {2, 4, 6}. The event occurs if the outcome ω lands inside A.
const isEven = (ω: Die) => ω % 2 === 0; // an event IS a predicate
const A = [1,2,3,4,5,6].filter(isEven); // …or equivalently, the subset it selects: [2,4,6]

3 · P: a function from events to [0, 1]

Finally, probability itself. P is just a function. It takes an event and returns a number between 0 (impossible) and 1 (certain) measuring how much of Ω the event covers — in the picture above, roughly "what fraction of the box does the region take up?"

P(A)  ("the probability of event A")
Plain language: the fraction of possibility-space that A occupies. P(Ω) = 1 — something must happen. P(∅) = 0 — the empty event never happens.
const P = (A: Set<Die>): number => A.size / 6; // for a fair die: measure = fraction of outcomes

When every outcome is equally likely (fair die, fair coin, shuffled deck), P has a beautifully simple implementation — and it's your first trophy:

🏆 Trophy Formula № 1
P(A) = |A||Ω|
Classical probability: favorable outcomes over total outcomes — valid only when all outcomes are equally likely. The bars |·| mean "size of the set", i.e. A.size.

So P(even) = |{2,4,6}| / |{1,2,3,4,5,6}| = 3/6 = 0.5. Theory says 0.5. But does the universe agree? Let's check.
