Notation Glossary

Every symbol earned so far — plain language first, TypeScript anchor second. Grows with each lesson.
SymbolRead aloud asPlain meaningTypeScript anchorEarned
Ω "omega" (the sample space) The set of every possible outcome of an experiment. type Die = 1|2|3|4|5|6 L1
ω "little omega" (an outcome) One specific outcome — a single realized result. const ω: Die = 4 L1
∈ "is an element of" Set membership: the thing on the left is inside the set on the right. set.has(x) === true L1
A ⊆ Ω "A is a subset of Omega" An event: any collection of outcomes carved from the sample space. Ω.filter(predicate) L1
P(A) "the probability of A" A function from events to [0, 1]: how much of possibility-space A covers. P(Ω)=1, P(∅)=0. (A: Set<Die>) => number L1
|A| "the size of A" (cardinality) How many elements the set A contains. A.size L1
∅ "the empty set" The event containing no outcomes — it can never occur. new Set() // .size === 0 L1
A ∩ B "A intersect B" (A and B) Outcomes where both A and B occur simultaneously — the overlap region. [...A].filter(x => B.has(x)) L2
P(A | B) "probability of A given B" Assuming B occurred, the fraction of B's outcomes that also satisfy A. The | means "filter to B first". Ω.filter(B).filter(A).length / Ω.filter(B).length L2
Convention worth memorizing: capital letters for sets/events/types (Ω, A, X), lowercase for individual values (ω, a, x) — exactly the Type vs value split in TypeScript.
