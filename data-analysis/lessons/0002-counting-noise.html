Counting Noise

A rate computed from a sample is a measurement with an error bar — and you can compute the error bar in your head, from n alone.

The win By the end (~10 min): given any daily rate, you can compute how much it should wobble from pure chance — and judge whether a swing is signal or breathing before anyone opens a debate about it.

01A day's orders are a random draw

Fix the truth completely: say Talbots desktop has a true conversion probability p = 3% that never changes. Each visit is still an independent coin flip, so the day's order count is a draw:

O ~ Binomial(V, p)
daily Orders are distributed as: V independent visits, each buying with probability p
// decoder: ~ declares the generator O was drawn from
const O = binomialDraw(V, p);   // 350 flips of a 3% coin → some count near 10.5

The rate you observe is therefore an estimate, and it gets the hat:

p̂ = O/V
the observed rate ("p-hat") = Orders ÷ Visits — an estimate of the true p, not p itself

Same truth, different day, different p̂. The whole question of this lesson: by how much?

02The formula, in four lines

Line 1. One visit is a 0-or-1 variable. Its variance (Var) comes straight from the definition:

Var(X) = E[X²] − E[X]² = p − p² = p(1−p)
variance of one visit = chance it buys × chance it doesn't

Line 2. The observed rate is just the mean of V such flips: p̂ = (1/V)·ΣXᵢ.

Line 3. Averaging n independent things divides variance by n — errors partially cancel. This is the mechanism behind everything in this lesson:

Var(x̄) = Var(X)/n
variance of an average = variance of one draw ÷ how many draws you averaged

Line 4. Take the square root to get back to readable units. That's the standard error:

SE(p̂) = √( p(1−p) / n )
Standard Error of the observed rate = √(one visit's variance ÷ number of visits)
// decoder: the whole derivation is three expressions
const varOneVisit = p * (1 - p);        // line 1
const varOfRate   = varOneVisit / n;    // line 3
const se          = Math.sqrt(varOfRate); // line 4

Notice the n lives under a square root: noise shrinks as 1/√n. To halve the noise you need four times the data. That asymmetry is why pooling weeks works and staring at days doesn't.

03The mental shortcut: 1/√count

For rare events there's an even faster version — a count wobbles by about its own square root:

O ± √O        relative noise ≈ 1/√O
ten orders is really 10 ± 3 — anything built from them is a ±32% instrument

This one line is the whole "why 10 orders can't tell you anything" argument, and it works on anything: 250 pooled orders → 1/√250 ≈ ±6%. 10,000 beacon sessions → ±1%. Memorize it.

05The real day, checked

Aug 24 desktop, from lesson 0001: control p̂ = 10/354 = 2.82%, test p̂ = 16/331 = 4.83% — a +71% CVR lift. Signal or breathing? Compute each arm's SE, then the gap in noise units (z) before revealing.

reveal the check 
SE_C = √(.0282 × .9718 / 354) ≈ 0.88pp        SE_T = √(.0483 × .9517 / 331) ≈ 1.18pp

gap  = 4.83 − 2.82 = 2.01pp
SE of the gap = √(SE_C² + SE_T²) ≈ 1.47pp     (independent noises add in quadrature)

z = 2.01 / 1.47 ≈ 1.4
the gap is 1.4 noise-units wide — under the |z| < 2 rule of thumb, breathing

So even the +71%-conversion day — the one that flattered the test arm — is statistically unremarkable on its own. The honesty cuts both ways: single days prove neither the scary story nor the nice one. Only pooling (28 days → SE shrinks by √28 ≈ 5×) turns +11.4% cumulative CVR into something real.

Where the |z| rule lives: the bell, with a slider

Gaps between identical arms pile up in a bell shape around zero (measured in noise units, z). Drag the threshold and watch the trade: the green middle is "gaps luck produces routinely," the red tails are "gaps this rare deserve attention." The famous stops: |z| ≤ 1 holds 68.3%, ≤ 2 holds 95.4%, ≤ 3 holds 99.7% — the |z| ≥ 2 rule is just "outside the 95% bulk."

06Check yourself

How you'd say it to a stakeholder A day of conversion data is a few hundred coin flips — and ten orders is a measuring stick with ±30% error bars baked in. When I pool four weeks the error bars shrink five-fold, and that's the number I trust. Judging the test by one day is like judging a coin by ten flips.
